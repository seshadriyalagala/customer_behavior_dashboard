This project analyzes **customer shopping behavior** using Python, SQL Server, and Power BI.

The project follows an end-to-end data analytics workflow:

**Data Collection → Data Cleaning → SQL Analysis → Power BI Dashboard → Business Insights**

# 1. 🐍 Data Analysis & Cleaning with Python

The dataset was initially loaded using Pandas and examined using:

* `df.head()`
* `df.info()`
* `df.describe()`
* `df.describe(include='all')`
* `df.isnull().sum()`

The original dataset contains 18 columns, including customer ID, age, gender, product, category, purchase amount, location, season, review rating, subscription status, shipping type, discounts, previous purchases, payment method, and purchase frequency.

### Missing Value Treatment

The `Review Rating` column contained **37 missing values**. These were filled using the mean review rating within each product category.

```python
df['Review Rating'] = df.groupby('Category')['Review Rating'].transform(
    lambda x: x.fillna(x.mean())
)
```

### Column Standardization

Column names were converted to lowercase and spaces were replaced with underscores.

```python
df.columns = df.columns.str.lower()
df.columns = df.columns.str.replace(' ', '_')
```

The purchase amount column was renamed:

```python
df = df.rename(
    columns={'purchase_amount_(usd)': 'purchase_amount'}
)
```

This transformation is implemented in the project code.

### Feature Engineering

An `age_group` column was created using quartiles.

```python
df['age_group'] = pd.qcut(
    df['age'],
    q=4,
    labels=['Young Age', 'Adult', 'Middle Age', 'Senior']
)
```

A numerical purchase-frequency feature was also created:

```python
df['purchase_frequency_days'] = (
    df['frequency_of_purchases'].map(frequency_mapping)
)
```

This converts categories such as Weekly, Monthly, Quarterly, and Annually into approximate numbers of days.

### Removing Redundant Data

The project checks whether `discount_applied` and `promo_code_used` contain identical values. Since the comparison returned `True`, `promo_code_used` was removed to avoid redundancy.
